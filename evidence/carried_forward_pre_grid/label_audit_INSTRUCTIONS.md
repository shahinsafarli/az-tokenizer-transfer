# Etiket auditi — təlimat (T6)

Bu vərəqdə 100 Azərbaycan dilində mətn var. Hər sətrə **öz** rəyinizlə,
digər auditorla MƏSLƏHƏTLƏŞMƏDƏN, aşağıdakı etiketlərdən BİRİNİ yazın:

    negative / neutral / positive / unclear

`your_label` sütununu bu adlardan biri ilə (böyük/kiçik hərf fərq etməz) doldurun.
Mətnin duyğusu AYDIN DEYİLSƏ (məs. çox qarışıq, yaxud anlaşılmazdırsa), məcburi
təxmin ETMƏYİN — `unclear` yazın. Təxmin uzlaşma faizini süni şəkildə şişirdir və
məhz ölçmək istədiyimiz etiket keyfiyyətini gizlədir.

## Sərhəd hallar üçün qaydalar (bunlar OLMASA hər auditor öz qaydasını
icad edəcək, və ölçdüyünüz şey ETIKETLƏR yox, TƏLİMATIN boşluğu olacaq):

1. **Tərif VƏ şikayət qarışıqdırsa** → hansı GÜCLÜDÜRSƏ o götürülür; bərabərdirsə → `unclear`.
2. **Sarkazm/istehza** → NƏZƏRDƏ TUTULAN mənaya görə qiymətləndirin, hərfi mənaya görə YOX.
3. **Duyğu ifadə etməyən sual** → `neutral`.
4. **Sadə faktiki cümlə** → açıq-aydın narazılıq ifadə etmirsə, `neutral`.
5. **Kəsilmiş, mənasız (garbled) və ya Azərbaycan dilində OLMAYAN mətn** → `unclear`.
6. **Söyüş/kobud söz TƏK BAŞINA etiket DEYİL** — ətrafındakı duyğuya görə qiymətləndirin
   (kobud sözlə deyilmiş müsbət rəy YENƏ DƏ `positive` ola bilər).

Dataset-in öz etiketi (gold label) bu vərəqdə YOXDUR — bu, qəsdəndir: məqsəd sizin
MÜSTƏQİL mühakimənizi ölçməkdir, əvvəlcədən verilmiş etiketi təsdiqləmək yox.

Doldurduqdan sonra faylı olduğu kimi (sütun adlarını dəyişmədən) geri göndərin.
